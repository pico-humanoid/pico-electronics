# 供电方案

## 电源板

- 采用 RobStride 电源板（[商品链接](https://item.taobao.com/item.htm?abbucket=0&id=1025248375262&mi_id=000048G5xOaak49ofo42Fry-inHjaAv6_2u7zB50EbCiXhg&ns=1&skuId=6202661899589&spm=a21xtw.29978516.product_shelf.10.2ba71cb7MmqAMo&xxc=taobaoSearch "进入淘宝")），详见[使用说明书](../datasheet/电源板使用说明V1.5_20260507.pdf "打开PDF")和[电源板3D模型](https://github.com/pico-humanoid/pico-mechanism/blob/main/Board/POWER_PCB_V1.3_1105.step "进入 GitHub 仓库")
- 外部输入：XT60接口
- 供电输出：
    - 主供电：XT30接口（无CAN）
    - 辅助供电：24V/4A、12V/2A、5V/2A
> ⚠️**注意：**
> 由于电源板不支持直接接入 XT30(2+2)，需单独设计电机 CAN 的集线接口。
