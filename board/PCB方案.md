# PCB 布局布线与制造版本

更新：2026-10-31。本页整理已保存设计及后续验收要求，本轮仅更新文档，不改动 CAD、制造订单或现有工艺设置。

## 当前设计

共享工程“主板v1.0 / 第1次改进”，双层、约 90×110mm，NUCLEO 排母、安装孔及整体功能布局沿用原版。近期主要整理三路 CAN 局部电路：

1. D1–D3 靠近对应 GH 外部接口，优化 H/L 入口与 TVS 接地路径。
2. 三个小终端开关分别靠近各路 120Ω 电阻，缩短终端支路，避免某一根 CAN 线单独远绕。
3. CANH/CANL 尽量成对、同层、平行、少折返；局部补偿改用嘉立创原生等长调节的低蛇形。
4. H6 附近 CAN2 两线绕开暂定的紧固件覆盖范围，并保留原网络和器件位置。
5. 随位置调整更新位号与功能标签，更新受影响泪滴、重建铺铜并重新检查 DRC。

## 布局布线原则

| 项目 | 本板采用的原则 |
| --- | --- |
| 布局 | 按接口、TVS、终端、收发器组成局部通道；电容贴近供电脚；兼顾插拔、开关操作及检修空间 |
| 走线 | 优先直接、简洁的路径，用 45° 转折处理需要的拐弯；不为美观增加大绕路或密集补偿 |
| 差分 | 对称的走向、完整回流、较短支路和合适拓扑优先；线宽线距需对应实际叠层，不能把任意 CAD 数值称为已验证的 120Ω 阻抗 |
| 换层与过孔 | 顶层贴片焊盘需通过合适过孔换到底层；地过孔可直接连接地铜，不一定要有独立底层导线；删除前先核对网络和铜连接 |
| 5V 线宽 | 按实际电流、温升、铜厚与压降安排；同名 5V 的主干和小支路允许不同线宽，不能单凭电压相同要求一样粗 |
| 铺铜 | 维持信号参考与连续回流，检查孤岛、细颈和未连通地；不能用铺铜掩盖断线、短路或错误网络 |
| 泪滴 | 用于焊盘/过孔与细线的平滑连接；修改走线后更新并检查，不能替代间距和连通性检查 |
| 丝印与图层 | Logo、位号、H/L、通道和电源标识保持可读并避开焊盘；丝印、装配参考线与铜在视图中相交需按图层判断，铜与同层异网铜相交才涉及电气连接/短路 |
| 机械 | 避开孔、螺丝头、垫圈和支撑柱的实际金属接触范围；阻焊不能作为防止螺丝磨损短路的唯一措施 |

教程里的 USB3、DDR、BGA、隔离或高压规则需按适用场景理解，不能直接把高速接口等长指标、统一线宽线距或爬电数值套到本板所有网络。

## 最近一次保存的检查记录

以下引用 2026-10-27 本地设计检查记录，本次没有重跑 CAD 检查。

| 检查 | 记录及边界 |
| --- | --- |
| DRC | 绕孔、泪滴与铺铜更新后，原生检查 141 项、0 错误；不是硬件功能、EMC 或量产验收 |
| CAN1 H/L | 整网铜线总长约 68.503225 / 68.502805mm |
| CAN2 H/L | H6 绕孔后整网铜线总长约 109.172020 / 109.172137mm |
| CAN3 H/L | 整网铜线总长约 100.536095 / 100.536324mm |
| 长度容差 | 保留原 0.254mm 规则；上述为含支路的整网总长，不代表逐端点匹配、实测时序或受控阻抗验收 |
| H6 避让 | 暂按紧固件覆盖外径 7mm；最近铜边距孔中心约 4.125mm，相对半径 3.5mm 约有 0.625mm 余量；实际外廓及安装公差仍需机械确认 |

当前经典 CAN 的板内短走线不应只追求微小长度差而牺牲主干拓扑、回流和机械间距。后续调整基于具体问题，避免为了“更等长”继续堆蛇形。
